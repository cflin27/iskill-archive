# Example Public PR Archive

This directory is an example skeleton, not validation evidence.

Use this shape for a real public PR only after confirming that every linked
repository, branch, model/workload, input, check, discussion, and result is
public-safe.

## Safety Notes

- Do not paste private logs.
- Do not include private prompts, media, datasets, checkpoints, hostnames,
  credentials, or local source patches.
- If a result depends on local-only evidence, state that it is not publishable
  until reproduced with public inputs and public code.
